How access works

Signing in with Clerk proves who someone is. Appearing in this list is what grants dashboard access. Anyone can create a customer account on the storefront; only these addresses reach the back office.

The address in the server's ADMIN_EMAIL variable is re-added on every restart, so it cannot be locked out by accident.
